## 4个Bug修复（第二轮）
### Bug A: 星球完成后不显示「今日已练」
- **根因**: `practicedToday` 的 useMemo 依赖 `[user?.id, records]`，但从QuizPage返回时父组件App.jsx的records是普通变量不触发re-render，导致practicedToday使用旧数据
- **修复**: 在 HomePage/EnglishHomePage/PoliticsHomePage 三个文件中加入 `refreshKey` + `visibilitychange` 监听机制，从quiz页返回时强制刷新计算
- **涉及文件**: HomePage.jsx, EnglishHomePage.jsx, PoliticsHomePage.jsx

### Bug B: 宠物升级后图片消失/与右下角不统一
- **根因**: Pet组件的精灵图(img标签)没有onError降级处理，升级后切换到新等级图片(如lv10→11)若加载失败则显示空白；MV1Demo的poolInfo已有fallback
- **修复**: Pet.jsx添加spriteErrorIdx状态+handleImgError回调+ALL_SPRITES备用图列表，dock模式和full模式的img标签均加了onError自动降级
- **涉及文件**: Pet.jsx

### Bug C: 自测星球AI出题 Load Failed
- **根因**: api/ai.js 的 bodyParser sizeLimit 设为 50kb，自测的完整试卷system prompt + AI返回JSON远超此限制，请求体被截断导致解析失败
- **修复**: sizeLimit 从 '50kb' 提升到 '4mb'
- **涉及文件**: api/ai.js

### Bug D: 诗词星球中途「题加载错误」
- **根因**: 题目数据异常（缺少type/question等关键字段）时DuolingoStyleQuiz显示"加载中"但无法继续答题
- **修复**: QuizPage增加isQuestionValid检测+自动跳过无效题目逻辑，遇到坏题自动跳到下一题或结束本轮并正常记录完成状态
- **涉及文件**: QuizPage.jsx

## Bug修复（第三轮）
### Bug E: 添加好友功能搜不到用户
- **根因**: MV1Demo.jsx 第164行 `userId.slice(0, 8)` 只显示前8个字符，但实际存的是完整UUID。用户手动输入截断的好友码去Supabase查完整user_id → 查不到
- **修复**: 
  1. 好友码显示改为完整UUID（不再截断）
  2. 字体调小+monospace保证完整显示不换行
  3. 提示文案改为推荐「复制」操作
- **涉及文件**: MV1Demo.jsx

### Bug F: 添加好友功能仍然不行（第二轮深入修复）
- **根因**: 好友添加只能按 `mv1_state.user_id` 精确匹配，但：
  1. 用户可能输入的是**对方名字**而非 user_id（如"小明" vs "小明_lz1abc1234"）
  2. 即使输入正确的好友码，目标用户若从未打开过宠物页面，`mv1_state` 表中没有记录 → 也查不到
- **修复**: 
  1. 导入 `findUserByName`（从 `sync.js`）
  2. 改造 `handleAddFriend` 为双策略查询：先按 user_id 查 mv1_state，失败后自动尝试按名字查 users 表获取真实 id 再查
  3. placeholder 改为「输入好友码或对方名字...」
  4. 错误提示优化为「请检查好友码或用户名」
- **涉及文件**: MV1Demo.jsx

### Bug G: 添加好友功能第三次修复（最终版）
- **根因**: 第113行 `if (!preview?.petEmoji)` 作为硬性门槛 — 即使找到了用户ID（通过findUserByName），如果对方没开过宠物页面 → mv1_state无记录 → preview为null → 被判定"未找到"
- **核心bug**: **必须要有宠物预览数据才能添加好友**，这完全不合理
- **修复**:
  1. 去掉 `preview?.petEmoji` 硬门槛
  2. 三层策略：user_id直接查 → 名字查users表获取真实id → 最终兜底确认用户存在即可添加
  3. 没有宠物数据的显示占位符（❓未知），不再阻止添加
  4. 成功提示改为「已添加xxx为好友 ✅」
- **涉及文件**: MV1Demo.jsx

  1. 好友预览只从 `mv1_state` 表获取数据，对方没开过宠物页面 → 无记录 → 显示 ❓??

  3. 添加好友时 fallback 写死为 `{petName:'??', petEmoji:'❓', ...}`
- **修复**:
  1. **双源获取**：好友预览同时从 `mv1_state`(宠物数据) + `users`(用户名) 获取
  2. 新增 `fetchFriendNames()` 函数批量查询 users 表
  3. 有宠物数据 → 正常显示 + 用户名补充
  4. 无宠物数据 → 用 users 表名字显示 🥚未孵化 占位
