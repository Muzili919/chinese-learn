## 点击互动修复（commit 9150f66）

### 问题1: Dock/互动页点击宠物不切换表情
**根因**: Pet.handleClick只触发内部happy(1.5s自动恢复normal)，pose prop优先级高于internalPose，所以Dock传的pose永远不变
**修复**: 
- Pet组件新增 `onTap` prop回调，点击时通知父组件
- GlobalPetDock: onTap → handlePetTap → dockPose循环切换（不再依赖Pet内部状态）
- MV1Demo: 新增 interactTapCount 状态 + INTERACT_POSE_SEQUENCE

### 问题2: 动作序列只有6个，缺少eating/reading/normal
**修复**: DOCK_POSE_SEQUENCE 和 INTERACT_POSE_SEQUENCE 都扩展到9个：
`reading → sleeping → happy → wave → excited → angry → sad_cry → eating → normal → 循环`

### 3. 蛋态Bug修复（commit fb402e3 — 第二次彻底修复）
**根因**: MV1Demo.jsx 初始化 currentPet 合并有缺陷
- 原代码: `cloud?.currentPet ? 云端 : base.currentPet(null)` 
- base = initGamificationState() → currentPet=null, ownedPets=[]
- 抽卡后切页面 → MV1Demo重挂载 → 云端可能未及时保存 → 变null=蛋态
**修复**: 三级优先级 — 云端 > initialState(本地) > null(蛋态)
- localHasPet && !cloudHasPet 时保留本地 currentPet + ownedPets
- ownedPets 同样应用合并策略
