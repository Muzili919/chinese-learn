# 如何添加题目

## 普通题目（字词/诗词/成语/句子/文学）

在对应的 JSON 文件里，按以下格式追加一条记录即可。

### 题目格式模板

```json
{
  "id": "vocab_101",
  "type": "single_choice",
  "question": "这里写题目内容",
  "options": [
    "选项一",
    "选项二",
    "选项三",
    "选项四"
  ],
  "answer": "选项二",
  "analysis": "这里写解析，告诉学生为什么选这个答案",
  "knowledge_tag": "字词",
  "ability_tag": "字音辨析",
  "difficulty": 2,
  "grade": 5
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| id | 是 | 唯一编号，不能重复。格式建议：`vocab_101`、`poetry_081` |
| type | 是 | 固定写 `"single_choice"` |
| question | 是 | 题目文字 |
| options | 是 | 4个选项，数组，纯文字（不要加A.B.C.D.前缀） |
| answer | 是 | 正确答案，**必须和options里某一项完全一致** |
| analysis | 是 | 解析，答错时显示给学生看 |
| knowledge_tag | 是 | 见下方表格，决定题目属于哪个星球 |
| ability_tag | 是 | 小分类，用于弱点诊断 |
| difficulty | 是 | 1=简单 / 2=中等 / 3=难 |
| grade | 是 | 4=四年级 / 5=五年级 |

### knowledge_tag 对应星球

| knowledge_tag | 对应星球 | 文件 |
|--------------|---------|------|
| `字词` | 字词星球 | questions_vocab.json |
| `古诗词` | 诗词星球 | questions_poetry.json |
| `成语` | 成语星球 | questions_idiom.json |
| `句子` | 句子星球 | questions_sentence.json |
| `文学常识` | 文学星球 | questions_literature.json |

### ability_tag 常用分类

**字词星球**
- 字音辨析、字形辨析、词语含义、近反义词、词语搭配、多音字

**诗词星球**
- 诗句默写、作者朝代、诗句含义、诗歌赏析

**成语星球**
- 成语含义、成语用法、成语辨析、近义成语

**句子星球**
- 修辞手法、句式转换、病句辨析、关联词

**文学星球**
- 四大名著、标点符号、体裁文体、作家作品

---

### 注意事项

1. **answer 必须和 options 中某项完全一致**（包括标点和空格），否则答题时会出问题
2. **id 不能重复**，每个文件内自行递增编号
3. **options 建议4个选项**，answer 的位置随意放（系统会自动打乱顺序）
4. JSON 文件最后一个 `}` 后面**不能有逗号**

## 阅读短文

在 `reading_passages.json` 里追加，格式如下：

```json
{
  "id": "passage_011",
  "title": "短文标题",
  "text": "短文内容，可以换行用\\n表示，一般200-400字",
  "grade": 5,
  "questions": [
    {
      "id": "pq_011_1",
      "question": "第一道题",
      "options": ["选项一", "选项二", "选项三", "选项四"],
      "answer": "选项一",
      "analysis": "解析",
      "ability_tag": "信息提取",
      "difficulty": 1
    },
    {
      "id": "pq_011_2",
      "question": "第二道题",
      "options": ["选项一", "选项二", "选项三", "选项四"],
      "answer": "选项三",
      "analysis": "解析",
      "ability_tag": "概括主旨",
      "difficulty": 2
    },
    {
      "id": "pq_011_3",
      "question": "第三道题",
      "options": ["选项一", "选项二", "选项三", "选项四"],
      "answer": "选项二",
      "analysis": "解析",
      "ability_tag": "理解感悟",
      "difficulty": 3
    }
  ]
}
```

**阅读题 ability_tag 常用分类**
- 信息提取（从文章找答案）
- 概括主旨（理解全文主题）
- 修辞赏析（分析修辞手法）
- 写作手法（分析写法特点）
- 理解感悟（深层理解）

## 添加完后怎么让网站更新

1. 保存文件
2. 用 git 提交并推送：
```bash
cd /Volumes/ORICO/新闻/claudecode/chinese-learn
git add src/data/
git commit -m "添加XXX题目"
git push https://<token>@github.com/Muzili919/chinese-learn.git main
```
3. Vercel 会自动检测到 GitHub 有新提交，1-2分钟后自动更新网站
