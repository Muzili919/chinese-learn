## 三、优化建议

### 仍可改进的方面

1. **难度微调**：基础题72题（目标70），提升题34题（目标35），拓展题14题（目标15）。差距很小（2-1题），不影响使用。如需精确匹配，可将2道基础题调整为拓展题。

2. **国情国策模块knowledge_tag颗粒度**：该模块只有10个不同标签，但24题。部分标签下有3-4题（如"习近平新时代中国特色社会主义思想"4题），建议细分（如"新发展理念""高质量发展"分开标注）。

3. **部分拓展题区分度**：0.7难度的拓展题与0.5难度的提升题在情境复杂度和选项迷惑性上的差异可以更明显。建议拓展题增加更多的"需要综合多个知识点才能判断"的设计。

4. **analysis中的"【解题口诀】"缺失**：部分宪法与法律模块的旧题analysis中包含"【解题口诀】"字段，但经过修复后可能丢失。可以统一添加记忆口诀。
