# 汉字星球 — 项目架构说明

## 项目简介

为小学5年级学生设计的语文自适应学习App，游戏化闯关形式，自动记录弱点，家长可查看报告。

- **技术栈**：React + Vite + Tailwind CSS
- **数据存储**：localStorage（本地）+ Supabase（云同步）
- **部署**：Vercel（自动从 GitHub 部署）
- **GitHub**：https://github.com/Muzili919/chinese-learn

## 核心逻辑

### SRS间隔重复
- 答对 → 下次出现间隔加倍（越来越少复习）
- 答错 → 明天重新出现（加强练习）
- 每次答题自动计时，答得慢的题也会标记为"不熟练"

### 弱点诊断
- 错误率 > 50% → 标记为弱点，优先出现
- 正确率 > 80% 但平均答题时间 > 15秒 → 标记为"知道但不熟练"

### 出题顺序（scheduler.js）
1. 今天到期的SRS复习题（最优先）
2. 从未做过的新题
3. 已做过但不急需复习的题
